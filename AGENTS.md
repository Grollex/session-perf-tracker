# Сводка папки

Эта папка содержит отдельный проект Session Perf Tracker.

- `SessionPerfTracker.slnx` — решение .NET.
- `src` — исходный код приложения, домена и инфраструктуры.
- `scripts` — сборка, упаковка и выпуск.
- `docs` — документация проекта.
- `installer` — файлы установщика Windows.

Работать только в рамках текущей папки. Не считать этот проект основным или приоритетным относительно других проектов пользователя.
